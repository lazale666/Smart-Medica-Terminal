# Qt客户端构建说明

## 环境要求

- **Qt版本**: Qt 6.x
- **编译器**: MinGW 64-bit
- **Qt模块**:
  - Qt Core
  - Qt Widgets
  - Qt Network
  - Qt Multimedia

## 构建步骤

### 方法一：使用Qt Creator（推荐）

1. **打开项目**
   - 启动Qt Creator
   - 点击 "打开文件或项目..."
   - 选择 `Client.pro` 文件

2. **配置项目**
   - 选择Kit（Desktop Qt 6.x MinGW 64-bit）
   - 点击 "配置项目"

3. **编译**
   - 点击左下角的 "运行" 按钮
   - Qt Creator会自动编译并运行程序

### 方法二：命令行构建

1. **打开命令行**
   - 进入项目目录
   ```bash
   cd Project_End/Client_Qt/Client
   ```

2. **生成Makefile**
   ```bash
   qmake Client.pro
   ```

3. **编译**
   ```bash
   mingw32-make
   ```

4. **运行**
   ```bash
   ./Client.exe
   ```

## 常见问题

### 问题1: qmake not found

**解决方案**:
- 确保Qt的bin目录在系统PATH中
- 或使用Qt Creator的完整安装

### 问题2: 缺少Qt Multimedia模块

**解决方案**:
- 在Qt Maintenance Tool中安装Qt Multimedia
- 或在Qt Creator中通过 "组件" 添加

### 问题3: 编译错误

**解决方案**:
- 清理构建目录：`mingw32-make clean`
- 重新配置：`qmake Client.pro`
- 重新编译：`mingw32-make`

### 问题4: 运行时缺少DLL

**解决方案**:
- 确保PATH包含Qt的bin目录
- 或将必要的DLL复制到可执行文件目录

## 目录结构

```
Client/
├── main.cpp              # 程序入口
├── widget.h/cpp         # 主窗口（登录、选择服务器、聊天）
├── networkmanager.h/cpp # 网络通信
├── voicemanager.h/cpp   # 语音管理
├── chatmanager.h/cpp    # 聊天历史管理
├── Client.pro          # Qt项目文件
└── build/              # 编译输出目录（Qt Creator自动创建）
```

## 运行前配置

### 1. 百度语音API配置

在 `widget.cpp` 的构造函数中添加：

```cpp
voiceManager->setBaiduCredentials(
    "你的AppID",
    "你的APIKey",
    "你的SecretKey"
);
```

### 2. 服务器地址

首次运行时在客户端界面输入：
- 服务器IP: 127.0.0.1（或服务器实际IP）
- 端口: 9999

## 构建输出

编译成功后，可执行文件位于：
- Debug模式: `build/Desktop_Qt_6_x_x_MinGW_64_bit-Debug/Client.exe`
- Release模式: `build/Desktop_Qt_6_x_x_MinGW_64_bit-Release/Client.exe`

## 部署

### Windows部署

1. **创建发布目录**
   ```bash
   mkdir Client_Package
   ```

2. **复制可执行文件**
   ```bash
   copy build\...\Release\Client.exe Client_Package\
   ```

3. **复制Qt运行时库**
   - 使用 `windeployqt` 工具
   ```bash
   windeployqt Client_Package\Client.exe
   ```

4. **复制配置文件**
   - connections.json
   - 聊天历史目录

## 性能优化

### 编译器优化

在 `.pro` 文件中添加：

```qmake
QMAKE_CXXFLAGS_RELEASE -= -O2
QMAKE_CXXFLAGS_RELEASE += -O3 -march=native
```

### Qt优化

- 使用Release模式构建
- 启用编译器优化
- 减少不必要的日志输出
